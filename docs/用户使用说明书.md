## 1. 安装与启动

### 1.1 免安装版（推荐）

1. 将 `视觉检测系统_免安装版` 目录复制到目标电脑任意位置
2. 双击 `启动系统.bat`
3. 等待后端引擎就绪（约 5-10 秒）
4. 系统界面自动弹出

**关闭方式:** 直接关闭主窗口，后台进程会自动清理。

> **注意:** 杀毒软件可能会拦截 `backend.exe`，首次运行时请添加信任。

### 1.2 直接运行（开发者）

```powershell
# 启动后端
.venv\Scripts\Activate.ps1
python -m backend.server

# 启动前端 (另一个终端)
cd view
npm run electron:start
```

### 1.3 首次启动检查

系统启动后会自动进行环境检测，检查项包括:
- MVS SDK 是否安装
- Python 位数是否匹配
- 相机 SDK 是否可初始化

如果检测未通过，状态栏左侧会显示警告，点击可查看详情（见[环境检测](#10-环境检测)）。

## 3. 运行检测

这是系统的主界面，显示 4 路相机的实时画面和检测状态。

### 3.1 界面布局

每个相机卡片包含三部分:

```
┌──────────────────────────────┐
│ Cam 1 | 线体 1 | 型号: 罐子A  │ ← 头部: 相机名、线体、产品型号、学习状态
│ [已学习]      [弹出] [详情]   │
├──────────────────────────────┤
│                              │
│       [待检测/正/反]          │ ← 图像区: 实时帧 + 检测结果徽章
│       (实时画面)              │
│                              │
├──────────────────────────────┤
│ 结果: 正 (95%)    12:00:00   │ ← 底部: 检测结果 + 时间戳
└──────────────────────────────┘
```

### 3.2 学习状态标识

头部型号右边会显示:

- **`[已学习]`** 绿色 — 该产品已完成 AI 训练，检测结果可信
- **`[未学习]`** 琥珀色 — 该产品未训练，检测结果是随机的，请前往设置页训练

状态每 10 秒自动刷新。

### 3.3 启动系统

**操作:** 点击 **`启动`** 按钮

**前置条件:**
- 必须已登录（未登录会弹出登录窗口）
- 系统当前处于停止状态

**点击后发生的事情:**
1. 系统检查各线体分配的产品是否有已训练模型
2. 连接配置好的相机
3. 设置相机参数（触发模式、曝光、增益等）
4. 加载对应产品的 AI 模型
5. 等待传感器触发信号

**启动成功后:** 按钮变灰（不可重复点击），状态灯变绿显示"运行中"，4 个相机卡片开始显示实时画面。

### 3.4 停止系统

**操作:** 点击 **`停止`** 按钮

**点击后发生的事情:**
1. 停止所有相机的取流
2. 断开相机连接
3. 停止推理 worker
4. 停止照片异步保存

停止后按钮恢复可点击状态，状态灯变灰。

### 3.5 状态栏统计

顶部右侧显示:
- **OK**: 累计正罐（合格）数量
- **NG**: 累计倒罐（不合格）数量
- **总计**: 总检测数

统计在每次检测后自动更新，停止后保留不清零（需在相机详情中手动清零）。

### 3.6 相机卡片内徽章

图像区左上角的徽章有以下状态:

| 徽章 | 含义 |
|------|------|
| 待检测 (灰色) | 相机未启动或未连接 |
| 等待触发 (灰色) | 相机已启动，等待传感器信号 |
| 正 (绿色) | 最新检测结果为正罐 |
| 反 (红色) | 最新检测结果为倒罐 |
| 错误 (红色) | 相机出现错误 |

### 3.7 弹出独立窗口

**操作:** 点击相机头部 **`弹出`** 按钮

将当前相机的画面弹出为独立窗口，方便外接显示器或单独监控。

- 点击后按钮变为 **`收回`**
- 关闭独立窗口也会自动收回
- 同时只能弹出一个窗口（点击另一个会自动关闭上一个）

### 3.8 查看相机详情

**操作:** 点击相机头部 **`详情`** 按钮

打开该相机的详情标签页（见[相机详情](#4-相机详情)），可关闭后切回运行页。

## 4. 相机详情

通过运行页面的"详情"按钮打开，以动态标签形式显示。

### 4.1 界面布局

```
┌────────────────────┬────────────────────┐
│                    │  照片保存设置       │
│   检测照片预览      │  ├ 保存正罐 [是/否] │
│   (大图)           │  └ 保存倒罐 [是/否] │
│                    │                    │
│                    │  检测照片历史       │
│                    │  ├ 2024-01-01 ...  │
│                    │  ├ 2024-01-01 ...  │
│                    │  └ ...             │
├────────────────────┴────────────────────┤
│  线体: 1  检测: 100  不良: 5  [清零]    │
└─────────────────────────────────────────┘
```

### 4.2 左侧: 检测照片

- 默认显示占位图
- 点击右侧历史列表任意照片 → 左侧显示该照片大图
- 照片从后端实时加载

### 4.3 右侧: 保存设置

- **保存正罐照片**: 开关，控制是否保存正罐（合格）照片
- **保存倒罐照片**: 开关，控制是否保存倒罐（不合格）照片

开关切换后实时生效，同步到后端。

### 4.4 右侧: 照片历史

显示最近检测的照片列表，每条记录包含:
- 时间戳
- 检测结果 (正/反)
- 文件名

**操作:**
- **左键点击**: 在左侧预览大图
- **右键点击**: 弹出上下文菜单 → 另存图片（仅技术员及以上权限）

### 4.5 底部信息

- 线体编号
- 检测数量
- 不良数量
- **`清零`** 按钮: 重置当前相机的统计数据（仅清零计数，不删除照片）

### 4.6 关闭详情

点击标签上的 **`×`** 按钮关闭，自动切回运行页。

## 5. 相机配置

### 5.1 打开方式

运行页 → 相机卡片头部 **`详情`** → 进入详情页后可点击相机参数设置，或通过设置页入口进入。

**权限要求:** 技术员或以上。

### 5.2 配置项详解

| 配置项 | 说明 | 推荐值 |
|--------|------|--------|
| **启用** | 是否启用此相机 | 勾选 |
| **IP 地址** | 相机 GigE IP | 192.168.1.x |
| **名称** | 显示名称 | Cam1 |
| **触发源** | 硬件触发信号输入口 | Line0 |
| **触发沿** | 上升沿或下降沿触发 | RisingEdge |
| **触发超时** | 等待触发信号的最大时间 (ms) | 30000 |
| **触发延时** | 收到触发到开始曝光的延时 (μs) | 0 |
| **曝光时间** | 传感器曝光时长 (μs) | 5000 |
| **增益** | 信号增益 (dB) | 0 |
| **去抖时间** | 滤除短脉冲干扰 (μs) | 50 |
| **频闪启用** | 是否控制频闪灯输出 | 按需 |
| **频闪延时** | 触发后到频闪输出的延时 (μs) | 0 |
| **频闪持续时间** | 频闪输出脉冲宽度 (μs) | 1000 |
| **剔除时间** | 倒罐剔除信号的持续时间 (ms) | 10 |
| **剔除延时** | 检测到倒罐后到发出剔除的延时 (ms) | 20 |
| **PLC 地址** | LECPServer HTTP API 地址 | http://127.0.0.1:8088 |

### 5.3 操作

1. 修改任意字段
2. 点击 **`保存`** → 配置写入 `data/camera_config.json`
3. 如已启动系统，需停止后重新启动才能生效

### 5.4 测试剔除

配置界面提供 **"测试剔除信号"** 按钮，点击后发送一次剔除指令到 PLC，用于调试气缸动作。

### 6.2 线体配置表 (左侧)

展示 4 条产线的当前分配:
- **线体**: 线体编号 (1-4)
- **检测产品型号**: 分配的产品名称
- **状态**: 已学习 / 未学习 / 未配置

如果产品未学习，该线体启动时将没有有效模型，检测结果为随机。

### 6.3 产品型号表 (右侧)

列出所有产品型号:
- **模型名称**
- **尺寸规格**
- **学习状态**: 已学习 (绿色) / 未学习 (琥珀色)
- **分配线体**: 下拉选择目标线体 (1-4)

### 6.4 分配产品到线体

1. 在产品列表中找到目标产品
2. 勾选左侧 **`☐`** 复选框
3. 在"分配线体"下拉中选择目标线体 (1-4)
4. 点击 **`传送`** 按钮

**效果:** 线体配置表即时更新，运行页面的相机卡片型号也会刷新。

**权限要求:** 技术员或以上。

### 6.5 新增产品

1. 点击 **`+ 新增产品`** 按钮
2. 弹出对话框，填写:
   - **型号**: 产品名称（例如"罐子A"）
   - **尺寸**: 规格描述（例如"Φ66×120mm"）
3. 点击"确定"

新增的产品初始状态为"未学习"，需前往设置页进行 AI 学习。

## 7. AI 学习

本页用于训练产品检测模型。

### 7.1 界面布局

```
┌──────────────────────┬──────────────────────────────┐
│   产品型号列表         │   学习控制                    │
│                      │                              │
│  型号  | 尺寸  | 状态  │  当前选择: [罐子A]           │
│  罐子A | ...  | 未学习 │                              │
│  罐子B | ...  | 未学习 │  [开始学习] [停止]           │
│                      │                              │
│  [搜索框]             │  ┌──────────────────────┐    │
│                      │  │ 训练进度条             │    │
│                      │  │ ████████░░ 80%       │    │
│                      │  │ Epoch 80/100 ...      │    │
│                      │  └──────────────────────┘    │
└──────────────────────┴──────────────────────────────┘
```

### 7.2 训练前准备

1. 准备训练图片，按以下目录结构组织:

```
图片目录/
├── 正/    ← 正罐（罐底朝下）的图片
│   ├── img001.jpg
│   ├── img002.jpg
│   └── ...
└── 反/    ← 倒罐（罐底朝上）的图片
    ├── img001.jpg
    ├── img002.jpg
    └── ...
```

2. 支持的图片格式: `.jpg`, `.jpeg`, `.png`, `.bmp`
3. **建议:** 每个类别至少 20-50 张，拍摄条件尽量接近实际产线环境

### 7.3 开始学习

1. 在左侧列表点击选择目标产品型号（选中后高亮）
2. 点击 **`开始学习`** 按钮

**权限要求:** 仅管理员。

### 7.4 学习确认弹窗

弹出窗口包含:
- 确认信息（产品型号名称）
- 如果已训练过，会提示"重新学习将覆盖原有模型"

**图片目录选择:**
- **正罐图片目录**: 点击"浏览"选择包含正罐图片的文件夹
- **倒罐图片目录**: 点击"浏览"选择包含倒罐图片的文件夹
- 或: 只填 **父目录**（包含 `正/` 和 `反/` 子目录）
- 两个目录必须同时指定

点击 **"确认学习"** 开始训练。

### 7.5 训练进度

训练启动后的进度显示:

| 元素 | 说明 |
|------|------|
| 进度条 | 整体进度百分比 |
| 进度文字 | 当前轮次/总轮次 + 阶段（冻结/微调） |
| 训练指标 | Epoch 编号 + 训练 Loss + 验证 Loss + 验证准确率 |

每轮结束后更新，准确率后面带 ★ 表示达到了最佳模型。

### 7.6 训练结果弹窗

训练完成（成功）后自动弹出:

- **产品型号**: 训练的产品名
- **数据分布**: 训练集/验证集图片数量
- **保存位置**: 模型文件路径
- **评估指标表:**
  - 准确率 (Accuracy)
  - 精确率 (Precision)
  - 召回率 (Recall)
  - F1 分数
- **混淆矩阵:** TP (真正例) / FP (假正例) / FN (假反例) / TN (真反例)

点击"确定"关闭。模型已自动加载，可直接启动检测。

训练的准确率达到 **95%+** 才建议投入生产使用。

### 7.7 停止学习

训练过程中点击 **`停止`** 按钮:
- 当前轮次完成后停止
- 不会保存模型
- 已训练的轮次数据丢弃

### 7.8 重新学习

如果已有模型的准确率不理想:
1. 增加训练图片
2. 选择同一产品型号
3. 重新开始学习
4. 旧模型会被覆盖

## 8. 模型测试

在不启动产线的情况下，用测试图片验证模型准确率。

### 8.1 界面布局

```
┌──────────────────────────────────────────┐
│  测试模型                                 │
│                                          │
│  选择模型: [下拉列表]                      │
│                                          │
│  模式: ○ 标注模式  ○ 推理模式              │
│                                          │
│  标注模式:                                │
│    正罐目录: [浏览...] D:\test\正         │
│    倒罐目录: [浏览...] D:\test\反         │
│                                          │
│  推理模式:                                │
│    图片目录: [浏览...] D:\test            │
│                                          │
│  [开始测试]                               │
│                                          │
│  ═══════ 测试结果 ═══════                 │
│  总数: 30  正确率: 96.7%                 │
│  正罐正确率: 100%  倒罐正确率: 93.3%     │
│                                          │
│  推理耗时: 最短 2.1ms  最长 8.5ms         │
│           平均 3.2ms  总耗时 0.10s        │
│                                          │
│  ┌──────────────────────────────────┐    │
│  │ 文件名    |期望|结果|置信度|耗时   │    │
│  │ img001   |正  |正  | 98%  |3ms  │    │
│  │ img002   |反  |反  | 95%  |2ms  │    │
│  │ ...                              │    │
│  └──────────────────────────────────┘    │
└──────────────────────────────────────────┘
```

### 8.2 选择模型

下拉列表显示所有已训练的模型，选择一个。

### 8.3 测试模式

**标注模式（推荐）:**
- 需要知道每张图的正反标签
- 分别指定"正罐目录"和"倒罐目录"
- 测试结果包含期望值对比，算出准确率

**推理模式:**
- 不需要标签，对任意图片目录做批量推理
- 只输出每张图的预测结果和置信度
- 不计算准确率

### 8.4 执行测试

1. 选择模型
2. 选择模式
3. 浏览选择对应目录
4. 点击 **`开始测试`**

### 8.5 结果解读

- **正确率 95%+**: 模型质量优秀，可用于生产
- **正确率 80-95%**: 可用但建议增加训练数据
- **正确率 <80%**: 需要检查训练数据质量或增加样本量
- **正罐/倒罐正确率差距大**: 某一类样本不足或不均衡

## 10. 环境检测

### 10.1 自动检测

系统启动时自动运行，如果发现问题会在状态栏左侧显示警告（黄色文字，可点击）。

### 10.2 查看详情

点击状态栏的警告文字 → 弹出环境检测详情弹窗:

- **摘要**: ✅ 全部通过 / ⚠️ 有 N 项警告
- **详细列表:** 每项一行，显示:
  - ✅/⚠️/❌ 图标
  - 检测项名称
  - 结果信息
- **点击某行** → 底部显示详细说明/建议

### 10.3 检测项目

| 检测项 | 说明 |
|--------|------|
| MVS SDK 安装 | `C:\Program Files (x86)\MVS` 目录存在 |
| Python 位数 | 64/32 位与 SDK DLL 匹配 |
| MVS SDK 导入 | `MvCameraControl_class` 模块可导入 |
| MVS SDK 初始化 | SDK 可成功初始化 |
| GigE 协议栈 | 千兆以太网协议可用 |

### 10.4 常见警告

- **MVS SDK 未安装**: 安装海康 MVS 客户端软件
- **Python 位数不匹配**: MVS SDK 需要 64 位 Python
- **GigE 协议栈不可用**: 检查网卡驱动和 MVS SDK 安装

## 12. 常见问题

### Q: 启动系统后相机画面一直是"等待触发"？

A: 正常。系统在等待传感器信号。如果没有传感器，可以临时切到连续采集模式（需修改相机配置的触发源为"连续"）。

### Q: 检测准确率很低？

A:
1. 确认已对该产品进行 AI 学习（查看相机卡片头部的学习状态）
2. 检查训练数据的质量和数量
3. 训练图片的拍摄条件应接近实际产线
4. 可在测试页做一次精度测试

### Q: 倒罐没有被剔除？

A:
1. 检查 PLC 地址配置是否正确
2. 检查剔除延时 (`rejectDelay`) 是否合适
3. 使用相机配置页的"测试剔除信号"验证 PLC 通信
4. 检查后端日志 `data/vision_system.log`

### Q: 无法连接相机？

A:
1. 检查相机 IP 配置是否正确
2. 检查网线连接和 GigE 网卡配置
3. 使用海康 MVS 客户端软件验证能否看到相机
4. 检查环境检测结果

### Q: 后端启动失败？

A:
1. 检查 5000 端口是否被占用: `netstat -ano | findstr 5000`
2. 检查杀毒软件是否拦截了 `backend.exe`
3. 查看后端日志

### Q: 前端显示"无法连接后端"？

A:
1. 确认后端已启动 (检查任务管理器中是否有 `backend.exe`)
2. 确认 5000 端口未被防火墙阻止
3. 检查 Vite 开发服务器是否正常运行（开发模式）
