## 1. 安装与启动

### 1.1 Windows 桌面版

1. 解压便携版，或运行 NSIS 安装包。
2. 启动“视界智检”。
3. 程序会自动启动本地检测后端。
4. 等待页面顶部状态恢复正常后开始操作。

桌面端默认连接本机 `http://127.0.0.1:5000`。关闭主窗口时，后端进程会一并清理。

### 1.2 Web 开发/局域网访问

需要分别启动后端和前端：

```powershell
# 项目根目录
python -m backend

# 另一个终端
cd view
npm ci
npm run web:dev
```

本机访问 <http://127.0.0.1:5173>。

局域网设备访问：

```text
http://<运行程序电脑的IP>:5173
```

Web 模式下，图片、训练目录和模型文件都位于后端电脑。选择目录时优先选择“后端目录”；网页端也支持在 Chrome/Edge 中点击“选择本地目录”调起目录选择器，但受浏览器安全限制只能回填目录名称，实际训练/测试路径仍需使用后端可见的目录。

### 1.3 默认账户

首次启动后端时会自动初始化默认管理员账号，**初始密码为随机生成**，会打印在后端启动日志中（形如“已初始化默认管理员账号，初始密码: xxxx”）。请在第一次登录后立即修改密码。

| 项目 | 默认值 |
| --- | --- |
| 用户名 | `admin` |
| 密码 | 首次启动时随机生成并打印在启动日志 |
| 权限 | 管理员 |

若提示无法登录，请查看启动日志中的初始密码，或在后端数据目录 `data/users.json` 中重置密码哈希。

### 1.4 后端登录鉴权（可选）

后端默认不要求登录（`VISION_AUTH_ENABLED=0`）。需要局域网防直连调用时，可在启动后端前设置环境变量 `VISION_AUTH_ENABLED=1` 启用：

```powershell
$env:VISION_AUTH_ENABLED = "1"
python -m backend
```

启用后，除登录和健康检查外的所有 API 都需要携带登录 token；前端在收到 401 时会自动弹出登录框。未登录前仍可查看运行页和说明书，执行受保护操作时需登录。

## 2. 登录与权限

| 角色 | 可用范围 |
| --- | --- |
| 管理员 | 所有页面、账户管理、密码和保持登录设置 |
| 技术员 | 运行、文件、设置、模型、PLC、测试；不能管理用户 |
| 操作员 | 运行页面的启动、停止和查看 |

未登录时可以查看运行页和说明书；执行受保护操作时需要登录。

登录信息的保存方式取决于运行形态：桌面端保存到应用数据目录，Web 端保存到浏览器本地存储。登录校验由后端完成（密码以哈希存储），前端在启用后端鉴权后会自动携带登录 token。不要在不可信网络中公开 Web 服务。

## 3. 首次配置

首次部署建议按以下顺序配置：

```text
线体数量 → 产品 → 产品与线体关系 → 相机 → 照片保存 → 模型 → PLC
```

### 3.1 设置线体数量

1. 打开“文件”或“设置”页面中的线体配置区域。
2. 设置实际使用的线体数量，范围为 1–16。
3. 保存后返回“运行”页，确认相机卡片数量正确。

### 3.2 创建产品并分配线体

1. 在“文件”页面新增产品。
2. 填写产品显示名称和模型关联名称。
3. 将产品分配到对应线体。
4. 确认运行页显示的产品/模型正确。

### 3.3 配置相机

在相机卡片中点击“配置”，或从“设置”页面打开相机配置：

- 触发源：`Line0`、`Line1` 或 `Software`；
- 触发沿：上升沿或下降沿；
- 触发延时和触发超时；
- 曝光、增益、帧率和其他相机参数。

参数必须与现场相机型号、IO 接线和触发方式一致。修改后建议先单独启动该线体验证。

### 3.4 设置照片保存

每个相机可以单独设置：

- 是否保存好品照片；
- 是否保存坏品照片。

照片由后端保存到 `data/captures/camN/`。长期留存的照片应复制到外部归档位置，不要依赖运行目录永久保存。

## 4. 日常运行

### 4.1 启动检测

1. 确认相机已上电并连接正常。
2. 确认产品和模型已分配到线体。
3. 打开“运行”页面。
4. 点击 **启动**。
5. 观察画面、类别、置信度、相机状态和统计数据。

启动后，系统会采集图像、执行模型推理、保存配置的照片，并根据模型设置触发 PLC 输出。

### 4.2 单独启停线体

系统运行时，可以在相机卡片中单独启用或停用某条线体。适用于单台相机维护、产品切换或故障排查。

### 4.3 调整运行布局

运行页支持：

- 单列大图；
- 双列标准；
- 三列紧凑；
- 四列总览；
- 主视图 + 缩略图；
- 自定义布局。

可以拖拽相机卡片调整顺序，布局会保存在当前客户端。

### 4.4 查看结果

相机卡片会显示：

- 最新画面；
- 等待触发/暂时无内容状态；
- 预测类别和置信度；
- 检测总数和异常数量；
- 相机、线体和后端连接状态。

“暂时无内容”通常表示相机尚未连接、尚未启动或尚未收到第一帧，不一定是系统故障。

### 4.5 查看相机详情

点击相机卡片的 **详情** 可以查看：

- 检测照片；
- 好品/坏品保存设置；
- 照片历史；
- 当前相机状态。

桌面端还可以点击 **弹出**，在独立窗口中查看指定相机。

### 4.6 停止检测

点击 **停止** 后，系统停止采集和检测，前端停止状态与画面轮询。停止后再修改相机、产品或 PLC 配置。

## 5. 模型训练与测试

### 5.1 准备训练目录

选择一个类别根目录，每个子目录代表一个类别：

```text
训练数据/
├─ 合格品/
│  ├─ ok-001.jpg
│  └─ ok-002.jpg
├─ 划痕/
│  └─ scratch-001.jpg
└─ 缺角/
   └─ missing-001.jpg
```

子目录名称会成为模型输出标签。类别名称应稳定、清晰，并与现场业务含义一致。

### 5.2 开始训练

只有管理员可以开始训练：

1. 进入“设置”。
2. 选择目标产品。
3. 点击 **开始学习**。
4. 选择类别根目录。
5. 确认模型名称和训练设备。
6. 点击确认并等待进度完成。

训练期间不要删除训练目录或强制关闭后端。

### 5.3 查看训练结果

训练完成后会显示模型路径、训练/验证数量和评估指标。训练历史可以在训练页面查看。

训练失败时检查：

- 类别根目录是否正确；
- 每个类别目录是否包含图片；
- 图片格式是否支持；
- 磁盘空间是否足够；
- PyTorch 和设备环境是否正常。

### 5.4 测试模型

进入“测试”页面：

1. 选择模型；
2. 选择测试模式；
3. 选择后端电脑可见的图片目录；
4. 执行测试；
5. 查看预测类别、置信度、准确率和计时明细。

有标签测试会使用类别子目录计算准确率；无标签测试只输出预测结果。

测试计时用于定位推理链路，不等同于整条生产线的最终节拍承诺。

### 5.5 设置模型类别和剔除规则

在“模型设置”页面：

- 为模型类别填写现场人员容易理解的说明；
- 勾选需要触发 PLC 的类别；
- 保存设置。

类别说明只改变界面显示，不改变模型标签。剔除类别必须与模型实际输出标签匹配。

模型卡片还支持 **重命名** 和 **删除**：

- 重命名会同步更新相机配置和后端引用登记；如果模型正被产品/线体引用，会先提示需要重新分配。
- 删除前系统会检查模型是否被产品/线体引用，被引用时拒绝删除并列出引用位置；删除操作不可恢复。

### 5.6 照片浏览与导出

在“文件”页面切换到 **照片浏览** 子页，可以：

- 按相机、结果（放行/剔除）和日期范围筛选照片；
- 分页查看照片列表；
- 按天或按小时查看良率趋势；
- 将筛选结果批量导出为 Zip 压缩包。

导出和趋势统计由后端完成，适合现场留存记录和分析。

## 6. PLC 配置

### 6.1 填写 PLC 参数

打开 **PLC** 页面，填写：

- PLC 服务地址；
- 节点名称前缀；
- 请求超时；
- 每个相机的拒绝时间、拒绝延时和拒绝信号节点。

节点名称、数值单位和写入时序必须由 PLC/自动化工程师确认。

### 6.2 测试 PLC

保存配置后，分别测试：

- 时间写入；
- 延时写入；
- 剔除信号。

测试前确认设备处于安全状态，避免误触发执行机构。建议先完成单点测试，再启动整线。

### 6.3 PLC 故障排查

1. 检查服务地址是否可达；
2. 检查节点名称和前缀；
3. 检查超时是否过小；
4. 查看后端日志；
5. 使用测试按钮验证单点写入。

## 7. 用户与系统维护

### 7.1 用户管理

管理员可以：

- 新建账户；
- 设置账户权限；
- 删除其他账户；
- 修改密码；
- 设置是否保持登录。

用户名不能重复，密码至少 3 位。当前登录账户不能删除。

### 7.2 环境检测

系统启动时会检查：

- Python、PyTorch 和 CUDA；
- CPU、内存、磁盘和网络；
- MVS SDK 和相机环境；
- 数据目录和基础配置。

警告不一定阻止启动，但错误通常表示对应功能不可用。

### 7.3 数据和照片维护

运行数据默认位于：

```text
data/
├─ captures/camN/       相机照片
├─ *_classifier_*.pth   模型
├─ camera_config.json   相机配置
├─ plc_config.json      PLC 配置
├─ device_config.json   设备配置
└─ vision_system.log    后端日志
```

需要迁移设备时，备份必要的配置和模型；不要直接复制现场账号、PLC 地址和日志到公共仓库。

## 8. 常见问题

### Q1：启动后一直“等待触发”或“暂时无内容”

检查系统是否启动、线体是否启用、相机是否连接、触发线是否接好，以及触发源和触发沿是否正确。尚未收到第一帧时显示暂时无内容属于正常中间状态。

### Q2：无法连接相机

确认已安装海康 MVS SDK，相机 IP、网卡和连接线正常，并确认相机没有被其他软件占用。然后查看环境检测和后端日志。

### Q3：检测准确率低

检查类别目录、标签一致性、样本数量、光照和拍摄角度。先使用独立图片在“测试”页面验证，再决定是否重新训练。

### Q4：剔除类别没有触发 PLC

确认模型实际输出标签与模型设置中的剔除类别一致，PLC 配置已保存，服务地址可达，并先使用 PLC 测试按钮验证写入。

### Q5：前端无法连接后端

确认后端正在运行，并访问 `http://127.0.0.1:5000/api/health`。同时检查前端是否使用 `npm run web:dev`，以及 5000/5173 端口和防火墙。

### Q6：训练按钮不可用

确认当前账户是管理员，训练目录包含类别子目录和有效图片，并确认没有其他训练任务正在运行。

### Q7：局域网页面能打开但不能读取图片/训练目录

图片和训练目录必须位于后端电脑。请在页面中选择后端目录，并检查后端电脑的防火墙和网络连通性。网页端“选择本地目录”只能回填目录名称，无法提供后端可用的绝对路径。
